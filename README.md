# Personal Expense Tracker

A beginner-friendly Python application for recording expenses, managing a budget, and understanding spending habits.

## Overview

The Personal Expense Tracker allows users to record and manage their daily expenses through a simple menu-driven interface. It helps users monitor spending, review expenses by category, and keep track of their budget.

## Features

- Add new expenses with a name, category, amount, and date.
- View all recorded expenses.
- Calculate total spending.
- Summarize spending by category.
- View today's expenses.
- Filter expenses by category.
- Set and update a spending budget.
- Receive warnings when spending approaches or exceeds the budget.
- Edit and delete existing expenses.
- Save expense records to a JSON file.
- Validate user input.

## How to Run

1. Install Python 3.
2. Clone this repository:

   `git clone https://github.com/chuks-dev1/personal-expense-tracker.git`

3. Open the project folder in your terminal.
4. Run the application:

   `python main.py`

   On some Windows installations, use `py main.py` instead.

## Data Storage

Expense records are stored locally in `expenses.json`. This file is excluded from Git version control to help protect personal expense data.
